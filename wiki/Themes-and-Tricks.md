## Trick 1 · The 10-second contrast test

Hold the proof next to the paper you'll print on. If the code "melts" into
the paper, change one thing:

```
   melting?               try
   ────────               ─────────────────────
   too faint        →     darker Code colour
   too loud         →     lighter Code colour
   weird glow       →     swap colours, then swap back (resets the palette)
```

## Trick 2 · Pictures that behave

| Picture kind | Best settings |
|---|---|
| Bold logo, 2 colours | Behind the code · 30–40% · Crisp |
| Cartoon / mascot | Behind the code · 50% · Screen |
| Busy photo | Behind the code · 70–100% · Dithered · Fade 40%+ |
| Signature / initials | Into the code · ≤ 40% · Crisp |

## Trick 3 · The print rehearsal

Always use **Print it** before the real run. The sheet carries a mini 2 cm
code — if *that* scans from arm's length, the big one is safe.

## Trick 4 · Secret-message games

```
  card 1: a Link code → to a riddle page
  card 2: a Text code → the riddle's answer clue
  card 3: a Wi-Fi code → "network name" is actually the prize code word
```

Codes make brilliant treasure hunts. The studio's Surprise-me! button writes
the clues for you.

## Trick 5 · Team colours in one click

Every Quick colour is a *pair* (code colour + paper colour) chosen to pass the
4.5 : 1 contrast rule — so picking any of them is always scan-safe.
