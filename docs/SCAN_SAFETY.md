# Scan Safety, Explained With Pictures

The studio checks all of this automatically — but the rules are easy enough
for anyone to learn. Here they are, the visual way.

---

## Rule 1 · Give the code breathing room

The empty border is called the **quiet zone**. Cameras need at least
**4 squares** of it on every side.

```
   ✗ crowded — artwork touches the code          ✓ happy — clear border
  ┌───────────────────────────────┐             ░░░░░░░░░░░░░░░░░░░░
  │🎨🎨 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ 🎨🎨│             ░░ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ░░
  │🎨   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓   🎨│             ░░ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ░░
  │🎨🎨 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ 🎨🎨│             ░░ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ░░
  └───────────────────────────────┘             ░░░░░░░░░░░░░░░░░░░░
        cameras get confused 😵                       scans fast ⚡
```

**In the studio:** the *Blank border* slider. Below 4, a warning appears.

## Rule 2 · Dark code, light paper

Cameras are trained to look for **dark marks on light ground** — like ink on
paper. The studio measures this as a *contrast number*.

```
   ✅ strong (≥ 4.5 : 1)      ⚠️ weak (3–4.5)      ❌ too faint (< 3)
  ┌──────────┐              ┌──────────┐         ┌──────────┐
  │ ▓▓▓▓▓▓▓▓ │              │ ▒▒▒▒▒▒▒▒ │         │ ░░░░░░░░ │
  │ ▓▓▓▓▓▓▓▓ │   on white   │ ▒▒▒▒▒▒▒▒ │  on     │ ░░░░░░░░ │  on
  │ ▓▓▓▓▓▓▓▓ │              │ ▒▒▒▒▒▒▒▒ │  cream  │ ░░░░░░░░ │  cream
  └──────────┘              └──────────┘         └──────────┘
     every phone               some phones           barely any
```

**In the studio:** the *Stands out on* cell turns green, amber or red for the
paper or fabric you picked.

## Rule 3 · Size it for the distance

The farther away people scan from, the bigger the code must be.

```
  📏 on a table           🧍 across a counter        🏪 on a poster
  ─────────────           ──────────────────         ─────────────────
     ▓▓▓▓▓                    ▓▓▓▓▓▓▓▓▓▓                 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
     ▓▓▓▓▓                    ▓▓▓▓▓▓▓▓▓▓                 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
   about 2 cm              about 4–5 cm                 15 cm or more

   🚫 never smaller than 2 cm — phones give up below that
```

**In the studio:** the print-size readout under the Save buttons says
"big enough to scan ✓" or "too small — make it bigger".

## Rule 4 · Tougher is better for paper

Paper gets scratched, folded and grabbed by sticky fingers. The safety level
decides how much damage the code survives.

```
  level L   survives ▓▓░░░░░░░░  ≈ 7%   (screens only)
  level M   survives ▓▓▓▓░░░░░░  ≈ 15%  (careful paper)
  level Q   survives ▓▓▓▓▓▓░░░░  ≈ 25%  (everyday paper)
  level H   survives ▓▓▓▓▓▓▓▓░░  ≈ 30%  (posters, stickers, pictures)
```

**In the studio:** the *Safety level* box. Adding a picture? Go to **H/Max**.

---

## Rule 5 · Pictures are welcome — with manners

A picture may live inside the code, but it must not cover the special squares
(corners, timing lines, alignment dot). The studio's two styles:

```
  STITCH — picture UNDER the dots          INLAY — picture AS dots
  ┌───────────────────┐                    ┌───────────────────┐
  │ ▓░▒▓░░▒▓░░▒▓░░▒▓░ │                    │ ▓░▒▓░   ░▒▓░░▒▓░░ │
  │ ░▒▓░▒▓░░▒▓░▒▓░░▒▓ │                    │ ░▒▓░▒   ▒▓░▒▓░░▒▓ │
  │ ▒▓░░▒▓░▒▓░░▒▓░▒▓░ │                    │ ▒▓░░▒▓░▒▓░░▒▓░▒▓ │
  └───────────────────┘                    └───────────────────┘
   safe at any size ✓                       keep ≤ half the width ✂
```

If a picture is too loud, the **Fade** control washes it toward the paper
colour — the #1 rescue for stubborn pictures.

---

## Rule 6 · Always test the real thing

Screens lie. The only true test is the actual print:

```
   🖨️ print it  →  📱 scan with two different phones
                    →  📐 try an angle
                    →  🌒 try dim light
                    →  🎉 all four pass? ship it!
```

**In the studio:** the *Print it* button creates a crop-marked sheet with a
built-in 2 cm mini-code for exactly this test.

---

## The studio's report card

Every check above appears live in the **Scan checks** list:

| Row | ✅ means | ⚠️ means |
|---|---|---|
| Clear border | ≥ 4 squares | too thin |
| Contrast | ≥ 4.5 : 1 | faint colours |
| Colour direction | dark on light | inverted (risky) |
| Your picture | within safe area | too big for Inlay |
| How busy it is | sparse enough | print it large |
| We scanned it for you | a real decoder read it back | needs rescue |

When every row is green, the code earns its **✓ ready to scan** badge — and
only then should it meet a printer.
